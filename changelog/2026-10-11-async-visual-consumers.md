# Shared asynchronous model consumers

World visuals, Studio equipment and mounted items now request one engine-managed hash-keyed CPU cache. Pending walk/test-drive geometry promotes without rebuilding physics; mounted pending misses are retried. Draw-time ownership keeps cached memory leased while used. Selected catalogue demand and limited row prefetch share the queue. F3 and observer resources expose residency and loading counters. Native hull/showcase loading and decoder peak-memory guarantees remain open; see `docs/ships/async-visual-consumers.md`.

Validation: registry build,175 workspace tests, explicit GPU upload test, four Studio captures and PBR warm-return fixture passed. CPU scene-return regression passed. Work remains on the isolated branch; main release binaries unchanged.
