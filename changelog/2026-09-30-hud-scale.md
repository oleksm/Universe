# 2026-09-30 — Smaller HUD text

## Summary

Feedback: screen fonts were so large they covered most of the screen. The HUD now renders on its
own layer at twice the scene resolution, so text is half the size while the 3D scene keeps its
chunky 270-line retro look.

## Changes

- Engine: separate HUD render target at `Config::hud_scale` × the scene resolution (default 2, so
  540 lines: an exact half of 1080p, so text pixels stay even). The blit pass composites scene +
  HUD (premultiplied alpha) with nearest filtering.
- `Frame::size()` and `Frame::project()` now use HUD-layer coordinates; `projected_radius()` still
  measures in scene pixels (used for level-of-detail decisions).
- Screenshots capture the composited image at HUD resolution (960×540 in screenshot runs).
- Game: scanner, velocity and fly-to markers, crosshair, target bracket and station marker scaled
  up so they stay readable; text stays small.
- Screenshot runs (`UNIVERSE_SCREENSHOT`) ignore keyboard and mouse input: a stray keypress into the
  popped-up window once toggled the docking computer mid-capture.
