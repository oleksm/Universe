# Mini apps on one engine

The game, the ship studio, the shipyard, the planet viewer, scenes and the factory layout studio
are apps on one engine host (`engine::apps`): one window, renderer, input and frame clock; a stack
of apps, only the top one taking keys. An app says what it does to the apps under it (`Cover`:
hides them, covers them while they run on undrawn, pauses them, or lets them run and be seen).
`freefall --apps` lists them; `freefall --app <name> [arg]` opens one alone; `freefall-planet` and
`freefall-studio` are the same apps' own binaries.

An app runs only the clocks it subscribes to, over a world instance of its own
(`sim::clocks::Runtime`): each clock at its record's period, slower first at the same moment,
waiting steps kept. Studio's DRIVE and WALK run on Realtime; the planet viewer on Celestial and
Planetary; a scene on what its file names (`content/scenes`); the factory layout on none.

The planet view (globes, full maps, ground patches, lines, air) is a shared part
(`game::planet_view`) the game, the planet viewer and scenes draw worlds with. The planet studio's
state and the shipyard's layer are gone from the game's `App`; both open over it as apps, and the
live world runs on under them. Plan and status: `docs/miniapps-plan.md`.

A test window is titled "Freefall test" whatever the app (it was "<app title> test", which the
window rule for workspace 8 did not match, so test windows of apps opened on the screen in use).
