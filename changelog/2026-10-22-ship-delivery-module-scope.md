# Separate module reuse from current delivery scope

An existing command station was included in a hull study although the owner had deferred the chair/dash. Correct catalogue ownership did not authorize its current inclusion.

The module inventory now carries a per-delivery included/installed versus deferred ledger. G3 and G7, module reuse/clearance checks and the release artifact require the actual source/build/render/export roster to match it. Deferred geometry, copies and proxies must be absent from the delivered source and views, including hidden or disabled collections, while product identity and future clearance data remain separate. Immutable library assets stay intact. Deferred functions and future fit are not accepted by absence.

This updates reusable definitions; current project geometry and operational integration still need their own exact-input review.
