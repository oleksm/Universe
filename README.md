# Freefall

*by Plurence*

A space game in which physics comes first: a seeded, open galaxy you can go anywhere in, with
ships flying on real thrusters and orbits under real gravity. It has an economy of players and
NPCs who do the same things, and a retro vector look. Written in Rust.

```
cargo run --release
```

The executable is `freefall`. Press F1 in the game for help. See `docs/architecture.md` for how
it's built and `changelog/` for what's changed.

(The code's crates keep their working names, `universe-*`.)
